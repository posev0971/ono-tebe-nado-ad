# Оно тебе надо

Вёрстка страницы аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/posev0971/ono-tebe-nado-ad

## О проекте

Одностраничный сайт вымышленного аукциона «Оно тебе надо». Учебный проект по HTML и CSS: страница сверстана по макету, без JavaScript и сборщиков.

## Структура страницы

- шапка с навигацией, логотипом и контактами;
- главный экран с заголовком, слоганом и кнопкой «Сделать ставку»;
- каталог лотов из трёх карточек;
- блок «Об аукционе»;
- подвал с контактами, навигацией и ссылками на соцсети.

## Технологии

- HTML5, семантическая вёрстка (`header`, `nav`, `main`, `section`, `article`, `address`, `footer`);
- CSS: Flexbox, Grid, CSS-переменные, методология БЭМ для именования классов;
- шрифт Raleway (Regular и Bold), подключён локально в форматах `woff2` и `woff`.

## Структура проекта

```
ono-tebe-nado-ad/
├── index.html
├── README.md
├── fonts/      # шрифты и fonts.css
├── images/     # фоны, карточки, логотипы и иконки соцсетей
└── styles/
    ├── global.css   # сброс и базовые стили
    └── style.css    # стили страницы
```

## Запуск

Сборка не нужна. Скачайте проект и откройте `index.html` в браузере.

## Ширина макета

Страница рассчитана на десктоп, ширина контента 1100px. Адаптивной версии нет.
